Chrome Management

Use these tools to recover from stuck jobs or a corrupted Chrome profile. All destructive actions also cancel any running or queued batch searches.

🔴

Kill All Chrome

Kills all Chrome processes and clears the job queue. Use when a batch is stuck but Chrome is already dead.

🟠

Soft Reset

Kills Chrome and clears corrupted cache, lock files, and preferences. Login sessions are preserved.

💥

Hard Reset

Kills Chrome and deletes the entire Chrome profile. All logins will be lost. Use only if soft reset fails.

🟢

Launch Chrome for Login

Opens Chrome on the virtual display. Use the VNC panel (bottom-right) to log in to sites manually.
